# ⚽ Calcetto Tracker

Web app per tenere traccia delle partite di calcetto del nostro gruppo.

## Funzionalità
- 👥 Gestione giocatori
- ⚽ Registrazione partite con composizione squadre e goal
- 📋 Visualizzazione cronologia partite
- 👤 Gestione utenti con ruoli (admin, manager, viewer)

## Tecnologie
- Streamlit (frontend + backend)
- PostgreSQL / SQLite
- streamlit-authenticator per il login

## Avvio locale
```bash
pip install -r requirements.txt
streamlit run app.py
```
